# Sourcing pass, 2026-09-18: labels for the first scanned module-40 identifiers

The supervised scan ([DEEP_SCAN.md](DEEP_SCAN.md)) found hundreds of
identifiers that answer service `22` at module `40` (priority `0x18`). A parked,
owner-attended experiment then found six that change with a deliberate state
change. This note records what public sources say about those six and about
their neighbours, so that borrowed labels become a **verification checklist**,
not decoded signals. Nothing here enters `ENHANCED_READ_DIDS`, `drive.py` or
`confidence.py`: that still requires cross-validation on this truck.

No payload values, VIN, MAC or raw frames appear in this document.

## The rule that decides whether a public label applies

**An identifier number is only meaningful within one module.** The same two
bytes name different data in different ECUs. A public label is evidence only
when it is for the same module (or a module shown to carry the same identifier
family), and preferably when the payload size agrees.

Two facts connect module `40` to one published family:

- The unmerged OBDb Cadillac LYRIQ PRs #13/#14 name identifiers at header
  `DA40`, and the same identifiers at the older battery module header `7E4`:
  `4149` EVSE pilot current, `416C–416E` HV group voltages, `434F`/`4127`/`4124`
  pack temperatures, `40E5`/`40E6` coolant temperatures. This project already
  reads those nine at module `40`.
- So module `40` on Ultium answers the identifier family that the 2017–2023
  Bolt and the Volt kept at `7E4`. Labels from **other** Bolt modules (for
  example the cell-voltage module `7E7`) do not transfer.

## The six state-change leads

Measured 2026-09-18 with `--watch`: a combined change (driver door open, lights
on, climate fan to max), a flip back, then one change at a time.

| DID | Size | Observed on this truck | Public label | Applies? |
|---|---|---|---|---|
| `423D` | 1 B | changed with the driver door alone; reverted | Bolt `7E7` "cell voltage #93", 3 B; OBDb make-level GM "HV battery module 93 voltage", `7E7` | **No** — different module and size |
| `423E` | 1 B | same as `423D` | Bolt `7E7` "cell voltage #94" | **No** |
| `41B5` | 1 B | changed with the climate fan alone; reverted | Bolt and Volt `7E4` "battery heater commanded power" (W), 2 B | **Family yes, encoding no** — thermal, but size differs |
| `41A9` | 1 B | changed with the climate fan alone; reverted | none found | — |
| `4120` | 1 B | moved with the fan; noisy otherwise | none found | — |
| `41AC` | 1 B | moved with the fan; noisy otherwise | none found | — |

No public source names a door, lock, lighting or cabin-climate identifier for
any Ultium vehicle. Owner forums for the Lyriq, Silverado EV and Hummer EV report
the same gap, and Car Scanner ships no profile for them. The door leads are
therefore new and must be confirmed by repetition, not by citation.

Structural support for the fan leads: the Bolt `7E4` neighbours `41B0`
("14 V power available"), `41B2` ("cabin AC measured W") and `41B4` ("cabin
heater measured W") all answer at module `40` too. The `41Ax–41Bx` block is
GM's cabin-thermal and power block on the older platform.

## Borrowed labels to verify (same family, same 1-byte size)

Bolt `7E4` labels for identifiers module `40` answers, where the Bolt equation
also reads one byte. Each has a parked check that does not depend on the label
being right:

| DID | Bolt label | Parked verification |
|---|---|---|
| `434A` / `434F` | pack module min / average temperature | min ≤ average; track the recorder's pack temperatures |
| `434B` / `434C` | hottest / coldest module number | small integer within the module count; stable |
| `432A` / `432C` | minimum / maximum cell number | integer within the cell count |
| `4357` / `4358` | electronics coolant pump commanded % / speed | move with charging or thermal load |
| `4359` / `435A` | battery coolant pump commanded % / speed | as above |
| `4310` / `4311` | HV interlock circuit / status | differ between truck off and ready |
| `433F` | minimum SOC limit | constant |
| `435F` | SOC variation | small, slow-moving |
| `41B7` | charging limit | changes with charging |
| `41A5`, `43C0` | unknown on the Bolt too | none |

Where the Bolt reads two bytes (`41B0`, `41B2`, `41B4`, `41B5`, `432B`, `432D`,
`433B`, `436B`, `436C`) the Ultium encoding differs; treat those names as hints
about the subsystem only.
